PROPOSED PRODUCTION DESIGN

Architecture on
Amazon Web Services

The proposed architecture supports document comparison and review workflows. The interactive demo uses sample data.

  1. 01

    Document intake

    Amazon Cognito

    Authenticate reviewers before document intake.

  2. 02

    Versioned storage

    Amazon S3

    Store versioned specifications, artwork, and report exports.

  3. 03

    Extraction and checks

    Textract + Lambda

    Extract scanned text and tables; run exact quantity and code checks.

  4. 04

    AI-assisted comparison

    Amazon Bedrock

    Suggest semantic discrepancies using supplied source evidence.

  5. 05

    Human review

    DynamoDB + Lambda

    Store findings, assignments and decisions; coordinate processing and reports.

Exact checks ≠ interpretation. Lambda handles deterministic field checks. Bedrock assists with meaning and explanations; reviewers evaluate the evidence.

No AWS services are connected to this demo. Website hosting is a separate choice from the proposed SaaS infrastructure.
